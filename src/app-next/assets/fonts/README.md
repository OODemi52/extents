# Inter

`InterVariable.woff2` is the upright variable font distributed by the Inter
project: https://rsms.me/inter/font-files/InterVariable.woff2

Retrieved October 10, 2026. The font is bundled locally so the interface does not
request typography from an external service. Its SIL Open Font License is included
in `LICENSE.txt`, from https://github.com/rsms/inter/blob/master/LICENSE.txt.
The same license is included in `public/Inter-OFL.txt` so frontend builds retain it.
